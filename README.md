# DealerConnect — Dealer Communication Portal

Next.js (App Router) + React + JavaScript + Material UI front end for finding dealers by
country / region / sector and communicating with them, plus Excel sales upload and a
12-month sales forecast. Data comes from the Python API in [`backend/`](backend/README.md)
(FastAPI + PostgreSQL).

## Run it

Two terminals:

```powershell
# 1. API (from the backend folder; first-time setup: see backend/README.md)
cd backend
.venv\Scripts\python -m uvicorn app.main:app --reload --port 8000
```

```powershell
# 2. Frontend (from the project root)
npm install
npm run dev          # http://localhost:3000
```

Sign in as `john.smith@abc.com` with the password you chose in `python -m app.cli setup`.

`.env.local` sets `API_ORIGIN` (default `http://localhost:8000`). The browser only talks to
`http://localhost:3000`; requests to `/api/v1/*` are forwarded to the API by the rewrite in
`next.config.mjs`, so the API's httpOnly auth cookies stay first-party. Rewrites are resolved at
build time, so set `API_ORIGIN` before `npm run build` too.

## Data sources

| Data | Where |
|---|---|
| Dealers, company, users, communications, sales uploads, exchange rates | PostgreSQL (schema `dcp`) via the API |
| Seed data | `dealers.json` + `sector.json` (project root) → `database/03_seed.sql` (generated by `database/generate_seed.py`) |
| Demo workbook | `public/samples/sample_sales.xlsx` (the API loads it for "Load sample file") |

## Structure

```
src/
  app/                 routes; (portal)/ holds the authenticated pages; /login, /reset-password
  proxy.js             sends signed-out visitors of protected pages to /login (cookie hint only;
                       the API validates every request)
  components/          layout, auth, dealers, filters, communication, sales, forecast, charts, ui
  services/            authService, dealerService, companyService, communicationService,
                       salesService, settingsService — thin wrappers over the API
  lib/apiClient.js     fetch wrapper: cookies, CSRF header, silent refresh on 401, ApiError
  lib/                 sectorMatching, salesAnalytics, salesForecast, fx, format, theme
  store/               Redux Toolkit: sales workspace, dealer list state, settings
  hooks/  types/
backend/               FastAPI + SQLAlchemy + Alembic (see backend/README.md)
database/              SQL schema, seed and generators
docs/backend/          backend plan and ERD
```

Behaviour notes:
- **Settings:** dealer-list preferences are saved per user by the API; the developer options
  (simulated errors / extra latency) stay in the browser.
- **Sales:** workbooks are parsed and stored by the API. The open workbook lives in Redux (a
  browser refresh closes it), and previous uploads can be reopened from "Recent uploads".
  Analytics and the forecast are calculated in the browser from the uploaded rows; the API
  offers the same calculations at `/api/v1/sales/analytics`.
- **Exchange rates:** loaded from the API; administrators can save company rates.

## Sales forecasting (Sales Forecast page)

- **History**: monthly totals from the uploaded sheet (Month + Year → period, Amount → value);
  months inside the range without rows count as 0.
- **Currencies**: pick one currency (no conversion) or "All currencies", which converts using
  the company's exchange rates.
- **Model**: 24+ months → Holt-Winters additive (12-month seasonality); 6–23 months →
  simple / Holt / damped-Holt exponential smoothing chosen by AICc; 3–5 months → linear trend;
  otherwise no forecast is produced.
- **Bounds**: 95% prediction intervals from in-sample one-step-ahead residuals, floored at 0.
- **Scenarios**: 16th / 84th percentiles of 2,000 seeded simulations of the 12-month total.
